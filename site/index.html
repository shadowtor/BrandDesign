Three logo sketches first. The whole brand after you pick one.

brand-studio is a skill for Claude Code, Codex CLI and Gemini CLI. Give it a business brief. It researches the category, draws three greyscale sketches, has a second agent review them, and stops. You choose, and then it builds the kit.

Pick a sketch (fictional example brands; the sketch stage is greyscale)

Choose one and it turns to colour, with the merch the skill picked for that kind of business.

How it works

  1. BriefYou describe the business, the audience and how it should feel. Anything missing becomes a stated assumption you can correct.
  2. ResearchIt compares the category with 1,400 reference logos and brand palettes, and lists the clichés to avoid.
  3. Three sketchesThree different ideas as black SVG, tested at 16 px, in one colour and reversed.
  4. Independent reviewA second agent that knows the business but not the favourite looks for look-alikes, odd readings and weak craft.
  5. You chooseThe skill stops here. No colour and no kit until you pick a sketch.
  6. The kitColour, outlined type and lockups, then every file below. A second review checks the result.

What the kit contains

Logos
Five forms: square, horizontal, vertical, symbol, wordmark. Each comes in full colour for light grounds, full colour for dark grounds, plus black, white and greyscale. Files are SVG, PNG, JPG and PDF.
Favicons
The full icon set with a test report: ICO contents, sizes, manifest, safe zone, and legibility at 16 px on light and dark tabs.
Social
Avatars and banners for LinkedIn, X, Facebook, YouTube, link previews and Instagram.
Stationery
An A4 letterhead with matching header and footer strips, a business card print file with bleed, and an email signature.
Merch mockups
Items that suit the business. Photographic where a free PSD exists, drawn and labelled where none does.
Guidelines and tokens
A PDF built from the real files, plus colour tokens for CSS, SCSS, Tailwind and DTCG.

Install

You need Python 3.9 or newer, a Chromium-based browser (Chrome, Edge, Brave) and internet access for fonts. uv is recommended.

Claude Code

/plugin marketplace add shadowtor/BrandDesign
/plugin install brand-studio@brand-studio

Codex, Gemini or another agent

git clone https://github.com/shadowtor/BrandDesign.git
cd BrandDesign
python tools/install.py --codex
Or paste this into your agent and let it install the skill 
Install the "brand-studio" Agent Skill for me.

1. Clone https://github.com/shadowtor/BrandDesign (or git pull if I already have it) and read
   docs/INSTALL-FOR-AGENTS.md in it. Follow that file exactly.
2. Install it for the agent I am using right now (python tools/install.py --claude, --codex or --gemini).
   Only copy the skills/brand-studio folder; do not change anything inside it.
3. Run: python skills/brand-studio/scripts/check_setup.py. If it reports a FAIL, show me the line and its fix and stop.
4. Tell me where it was installed and the check result, and that I must start a new session.
   Do not commit, push or download anything else.

After installing, start a new session and ask: "Design a brand identity for my coffee roastery. Show me three logo sketches first."

What it will not do for you

  • It does not clear trademarks. Search your market's register before you launch.
  • CMYK values are derived from screen colour, and Pantone is left blank. A printer needs to proof the real thing.
  • The favicon test uses a simulated browser tab. Open the live site once in a real browser.
  • Mockups are previews, not artwork to publish. Third-party PSD files are never redistributed.
